## 二、跨语法通用规律（12 条，换任何风格都成立）

1. **镜头只由时间决定，场景按镜头重画。** 推拉、平移、穿越都是同一张「世界画布」在不同镜头下重画，放大不糊；不要把渲染好的整帧位图放大当推镜。
2. **缩放用对数插值**（每帧放大同样倍数），线性插值会前慢后猛；穿过圆形开口时放大倍数要够（约 画面对角半径 / 开口半径）。
3. **「揭开」那一帧对准口播的词。** 重音不是转场第一帧，而是新画面露出来那一帧；数字在念到数值时**落定**（计数起点 = 念数字时刻 − 计数时长）；白板开写比对应短语晚约 0.5 秒，说完 1 秒内写完，不抢先。
4. **先结构、后数据、最后只标一件事。** 坐标系先出、数据再长、标注最后；先写问题再演示。
5. **一屏一个焦点。** 同一时刻只让一个东西入场，其余静止；主词和辅句字号至少 3:1；背景饱和度、对比、线宽都比主角低一档。
6. **入场慢、退场快，落定后要停。** 入场 0.3–0.4 秒、退场约 0.18 秒；数字落定后至少停 0.5 秒，包袱后定住 ≥0.9 秒，每个讲解动画后停约 1 秒。
7. **「一直在动」还是「快切后定住」按语法选，别混。** 扁平科普几乎没有完全不动的时刻；storytime 七成帧静止，生命在快切＋定住。
8. **两层帧率：镜头平滑，元素步进。** 拼贴里镜头丝滑、纸片和荧光笔按 12 帧/秒一顿一顿；storytime 角色 24 帧/秒、镜头 60 帧/秒。全丝滑像企业宣传片，全步进会晃。
9. **颜色＝概念，强调色少。** 一个颜色只讲一个概念，公式符号和画面里的物体同色；超过 3–4 种语义色观众就记不住。（本 Skill 已用 `T.c1/T.c2/T.key…` 语义色落实）
10. **转场放在换气和换话题处，不放在句子中间。** 甩镜切在两句之间，反应镜头放在沉默里，白板平移卡新论点。
11. **审片要查逻辑和数字口径，不只看好不好看。** 实测抓到过：「涨了 8.7 倍」应为「涨到原来的 8.7 倍」；全屏后又从 0 重数；两镜之间的数字推不出来。
12. **真实素材保持原样。** 截图等比放；数据只改「怎么出现」不改「是多少」；柱状图从 0 起，轴不从 0 要写明；虚构数据每镜标「示意数据」，真实数据不许出现这个角标。

## 三、9 种语法的要点（各一段；全文在原件 `references/动画语法/<名>.md`）

- **白板 y3**（学术主力，本 Skill 白板路线已实现）：说一句写一句，相机跟着论证在一张大板上移动，最后拉远看全图。每块停留约 6–7 秒；只用黑＋一个强调色；新区域和旧区域大面积重叠（平移约 1/4 画宽），只有跳远才甩镜；复杂插画预先画好、相机移过去露出来；手只在写的时候入画。
- **3B1B t1**（本 Skill Manim 路线已实现）：深底只放正在讲的那个东西，用形变把上一个概念直接变成下一个，几乎不切；默认 smooth 缓动，一个动画 1–3 秒后停 1 秒；每个动作对应口播里的一个动词；别加发光和深蓝渐变底。
- **storytime y4**（搞笑/经历）：口播是主角，画面是配口播的「表情包」。角色在几个姿势间 0.1 秒快切后定住（换姿势时身体压 7% 再回弹）；一句≈一镜，平均 2 秒左右；笑点靠**砸镜切到反应大特写并闭嘴 0.8–1.5 秒**；包袱后定住 ≥0.9 秒；背景比角色轻（线宽一半、低饱和）；角色入镜第一帧就已在位，只有道具和符号（？！汗滴）弹入。
- **动态文字 y5**（清单/金句/章节）：字就是演员，主词踩重音砸进来、0.35 秒后钉住不动，动感交给镜头和背景；同一套拍位重复，观众第二页起就知道下一下在哪；中文停留按 7–9 字/秒算够读（主词 2 字 ≥0.5 秒，辅句 7–8 字 ≥1 秒）；画面宁早勿晚，最多早 1 帧。
- **扁平科普 y1**（尺度/机制）：概念放进可以无限缩放的发光世界，镜头在尺度间穿行，每个元素入场后接一个待机小循环（浮、闪、呼吸）；深底＋2–3 个发光强调色，不描黑边，阴影用同色深一档；标注先画细引线再逐字打出。
- **Vox 拼贴 y2**（新闻/证据）：论证摆在铺着真实材料的桌面上，镜头像调查记者的眼睛移动；黑、纸白、一种红，加一种荧光笔色；照片随切点直接在，不搞撕纸和每张都弹入；荧光笔、打字、描线速度锁在念词速度上；竖屏框口播正在念的那半句。
- **发布会界面 t2**（产品/教程）：深色底漂移光斑，一屏一件事，字从模糊里浮出，卡片用轻回弹弹簧落位（回弹 ≤0.15–0.3，>0.4 就廉价）；名词说出前 0.2–0.3 秒开始浮现；密集段后放一屏空的给观众喘气；玻璃后面必须有东西可模糊。
- **财经图表 t3**（数字）：先搭坐标系→数据长出来→只标一件事；一个颜色讲主角其余变灰；标题写结论、副标题写指标与单位、左下写来源；倍数要能从图上的数算出来；不弹跳柱、不 3D、不转饼图。
- **纸片剧场 y7**（花伦自建，2026-10-11，参考一支抖音 AI 卡通 MV 的画风和节奏，角色换成暹罗猫）：扁平图形 + 深色描边 + 纸张颗粒，土色暗调；一张大场景（梯田、蘑菇顶小屋、大树、小卖部、台阶、电线杆）上**长镜头横移和推近、很少硬切**；角色骑摩托/走动，停下一压一弹；头顶弹 ？！、爱心想法泡；关键字大字砸到画面上；白天→黄昏→夜晚整体调色。代码在引擎副本 `clips/y7_paper.js`，cue：move / point / pose / mark / think / word / close / time / cam（写法见文件开头注释）。角色两种：暹罗猫（默认）、方块小人（`"kind": "box"`，可自填颜色/头带/小花；`"preset": "claude"` = 参考片里的 Claude 吉祥物式橙色方块，用户 2026-10-11 定可以用；它是 Anthropic 的品牌形象，用在讲 Claude 的内容里，别做成像官方出品的样子）。
- **讲解员 y6**（真人/卡通讲解员串联）：分镜先分配版式（侧身讲解、满屏数字、左右对比、角色进入图里、反应特写），别全片固定人左图右；数字念到才落定，计数中不提前出「超过」「+」；人物用生图帧，代码控位置和换帧。原件目前没有参数化片段，本 Skill 暂不接。

## 四、做一集的方法（导演层）

1. **一帧先行。** 先设计一帧「对的画面」再让它动：没有参考就先定场景骨架（标准构图坐标）。**新做一种风格或新角色**时，在同一帧上出三个方向给用户挑；用已有风格直接做，不走这步。
2. **每幕是活的画。** 每一幕至少一个主动作＋2 个取自该风格母题的小循环（storytime / 动态文字例外：动在节点上、静在笑点上）。
3. **转场用下一种风格的签名语言**（艺术风格速通类）：进梵高是笔触漩涡、进浮世绘是浪、进水墨是晕开；从画内某个物体长出来。
4. **镜头表先行。** 口播 → 每句一行「画面上是什么 + 景别 + 时长」，先给用户看 5–10 行再动手（长片才需要，1 分钟内的直接做）。
5. **cue 写「哪个词」，不写「第几秒」。** 动作挂在关键词上，渲染前再换算成时间；口播改了，时间跟着变。
6. **节奏网格。** 有配乐的蒙太奇先定 BPM，所有剪点落在网格上；加速靠每段变短，不靠提速；口播片让网格让位于口播（句间留白处放转场与音乐重音）。
7. **拆解参考片**（要复刻别人的动画时）：先量物理参数 → 接触表 + 关键帧总览 + 频谱图 → 逐帧灰度差找转场、拟合节拍网格 → 每个转场一张 60 帧/秒接触表看机制 → 运动热图看「画里哪里在动」。复刻是学机制，不是逐像素。脚本在原件 `scripts/analyze/`。
8. **画面美感**：区域色板比颜色抖动重要；大面积交给渲染器，小物件和角色单独一层；角色也要过同一种材质处理，否则像贴上去的；小东西要做得比直觉大；风格里的字用路径画更有风格。
9. **角色**：几何角色、火柴人、简笔可以代码画；真人和拟人角色用本机生图（`hualun-local-image-gen`）出帧、绿幕抠图，代码只管位置、大小、换帧和材质。
10. **确定性**：一切随机用种子，同一时刻渲两次逐像素一致，才能分段重渲再拼。

## 五、验收

- 本 Skill 已有：逐句配音核对、抽帧拼图自检（SKILL.md 第 3 步）。
- 吸收的：**按语法读运动量**——艺术速通要「一直活」；storytime/动态文字七成静止是风格，不是卡。**参数化片段要用「不友好」输入单独测**（长标题、负数、小数、无截图）。**动画让开字幕带**，而不是让字幕让开动画（片段路线用 `safe.bottom`）。
- 独立审片：原件要求交付前派一个没参与制作的 Agent 只看成片挑问题。按用户的 token 规矩，**默认不派**；长片或正式发布前，先问用户再派。

## 六、配音（只学免费的做法）

本 Skill 配音默认走免费 edge-tts，有本地配音 Skill 时用本地克隆声音，不用原件的付费语音。学到的做法：
- 已有录音直接沿用，不重新配。
- 每次只生成一条，不自动出三个候选。
- 补配一句后要核对台词、专名、接缝和字幕（本 Skill 的逐句有声核对 + 抽帧检查已覆盖）。
- storytime 的口型可以读口播音量包络（片段路线自动从本地配音算出来），声音大张大嘴、停顿闭嘴。
